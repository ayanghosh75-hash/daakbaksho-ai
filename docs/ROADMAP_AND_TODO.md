# 🗺️ ডাকবাক্স AI — ধীরে ধীরে উন্নয়নের রোডম্যাপ (Development Roadmap)

> **দর্শন:** তাড়াহুড়ো নয়, নিখুঁত কারিগরি দক্ষতা দিয়ে ধাপে ধাপে একটি বিশ্বমানের, আবেগঘন এবং লাভজনক ডিজিটাল প্রোডাক্ট গড়ে তোলা।

- [x] স্বচ্ছ ব্যাকগ্রাউন্ড সহ খাঁটি ভিন্টেজ লাল ডাকবাক্স আইকন তৈরি (১০২৪x১০২৪ ট্রান্সপারেন্ট পিএনজি)।
- [x] লোকাল কম্পিউটারে থাকা `Kalpurush.ttf` ফন্ট সফলভাবে যুক্ত করা।
- [x] খাঁটি ঝর্ণা কলমের নিব অ্যানিমেশন এবং ওয়েব অডিও খসখস সাউন্ড সিন্থেসিস।
- [x] প্রফেশনাল এআই স্টেনোগ্রাফার লজিক (প্রশ্নবোধক `?`, বিস্ময়বোধক `!`, দাঁড়ি `।`, দ্বিধা দূরীকরণ, তোতলামি ফিল্টার, স্বয়ংক্রিয় ভুল সংশোধন)।
- [x] মুখে বলে বাক্য মোছা ("মুছে ফেলো"), নতুন কাগজ নেওয়া ("সব মুছে ফেলো"), বাক্য বদলানো ("বদলে লেখো"), স্বাক্ষর ও কালি পরিবর্তন।
- [x] অটোমেটেড টেস্ট স্যুট তৈরি (`tests/test_stenographer.js` — ৮টি টেস্ট ১০০% পাস)।
- [x] পূর্ণাঙ্গ PWA সক্ষমতা (`manifest.json` ও `sw.js` অফলাইন সার্ভিস ওয়ার্কার)।
- [x] স্বতন্ত্র ডেডিকেটেড ফোল্ডারে সুসজ্জিত প্রজেক্ট আর্কিটেকচার (`D:\AI_Software_Business_Hub\4_DaakBaksho_AI\`)।

## 📍 ধাপ ২: ব্যবহারকারীর ডাটা সেভিং ও লোকাল মেমোরি আর্কাইভ (Data & Personal Vault)
- [ ] **লোকাল ড্রাফট অটো-সেভ:** ব্যবহারকারী যাই বলবেন, ব্রাউজারের `localStorage` বা `IndexedDB` তে সংরক্ষিত থাকবে; পাতা রিফ্রেশ করলেও লেখা হারাবে না।
- [ ] **পুরনো চিঠির ডায়েরি (Memory Vault Drawer):** বাঁদিকে একটি ভিন্টেজ কাঠের ড্রয়ার বা ফোল্ডার অপশন থাকবে, যেখানে পূর্বের লেখা চিঠিগুলো তারিখ অনুযায়ী সংরক্ষিত থাকবে।
- [ ] **কাস্টম ডিকশনারি:** পরিবারের নাম, ডাকনাম বা নির্দিষ্ট কলকাতার অঞ্চল/শব্দ স্টেনোগ্রাফারের শব্দকোষে যোগ করার সুবিধা।

## 📍 ধাপ ৩: কাস্টম ভিন্টেজ থিম ও কাগজের প্রকারভেদ (Vintage Stationery Studio)
- [ ] **কাগজের প্রকারভেদ:**
  - ভিক্টোরিয়ান হলুদ পার্চমেন্ট (Victorian Parchment - ডিফল্ট)।
  - রবীন্দ্রনাথের শান্তিনিকেতনের হাতে তৈরি পেপার (Handmade Khadi Paper)।
  - সত্তরের দশকের নীল পোস্টকার্ড (Iconic Blue Inland Letter / Postcard)।
- [ ] **ডাকটিকিট সংগ্রহশালা (Vintage Stamp Picker):** ভিক্টোরিয়া মেমোরিয়াল, হাওড়া ব্রিজ, ডাকটিকিট বা ডাক হরকরার বিভিন্ন ডাকটিকিট পছন্দ করার সুবিধা।
- [ ] **মোমের সিলমোহর (Custom Wax Seal Stamp):** ব্যবহারকারীর নামের আদ্যক্ষর দিয়ে মোমের লাল সিলমোহর বসানো।

## 📍 ধাপ ৪: সোশ্যাল মিডিয়া রিল ও অডিও এনহ্যান্সমেন্ট (Viral Creator Tools)
- [ ] **ব্যাকগ্রাউন্ড মিউজিক সিলেকশন:** চিঠির রিল তৈরি করার সময় আবহে হালকা শান্ত পিয়ানো, নস্টালজিক বেহালা বা বৃষ্টির মৃদু শব্দ যোগ করার অপশন।
- [ ] **ইনস্টাগ্রাম ও ইউটিউব শর্টস সাইজ (9:16 এবং 4:5 রেশিও অপটিমাইজেশন):** সরাসরি স্ট্যাটাস বা রিল আকারে সহজে শেয়ারযোগ্য।

## 📍 ধাপ ৫: মনিটাইজেশন ও গ্লোবাল রিলিজ (Monetization & Public Launch)
- [ ] **ফ্রি টিয়ার (বিজ্ঞাপন ভিত্তিক):** বিনামূল্যে ফুল এইচডি ফটো কার্ড ও রিল ডাউনলোডের জন্য ১০-১৫ সেকেন্ডের বিজ্ঞাপন দেখা।
- [ ] **ভিআইপি লাইফটাইম আনলক (₹২৯ বা $০.৯৯):** আজীবনের জন্য বিজ্ঞাপনমুক্ত আনলিমিটেড চিঠি, রিল এবং প্রিমিয়াম পোস্টকার্ড ডাউনলোড (সরাসরি Buy Me a Coffee / UPI / Stripe Payout)।
- [ ] **পাবলিক হোস্টিং (Vercel / Cloudflare 100% Free HTTPS):** বিনামূল্যে গ্লোবাল ইন্টারনেটে লাইভ করা, যাতে মোবাইল ফোন থেকে পুরো বিশ্বের মানুষ সরাসরি ডাকবাক্স ব্যবহার করতে পারেন।
